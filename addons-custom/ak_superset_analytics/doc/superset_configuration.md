# Apache Superset Configuration for Odoo Integration

This document provides the necessary configuration steps to set up Apache Superset for integration with Odoo using JWT authentication.

## Configuration Steps

1. Open your Superset `config.py` file (typically located at `/app/pythonpath/superset_config.py` in Docker installations or in your Superset installation directory)

2. Add the following configuration to enable JWT authentication and SSO:

```python
# JWT Authentication settings
JWT_SECRET_KEY = 'your-secret-key-here'  # Must match the jwt_secret in Odoo
JWT_ALGORITHM = 'HS256'

# SSO Custom Security Manager
from superset.security import SupersetSecurityManager
import jwt
from flask import request
import logging

class CustomSSOSecurityManager(SupersetSecurityManager):
    def oauth_user_info(self, provider, response=None):
        """Get user info from JWT token"""
        try:
            # Get JWT token from header or URL parameter
            token = request.args.get('jwt') or request.headers.get('Authorization', '').replace('Bearer ', '')
            
            if not token:
                return None
            
            # Decode token
            payload = jwt.decode(token, JWT_SECRET_KEY, algorithms=[JWT_ALGORITHM])
            
            # Return user information
            return {
                'username': payload.get('username'),
                'email': payload.get('email'),
                'first_name': payload.get('first_name', ''),
                'last_name': payload.get('last_name', ''),
                'role_keys': ['Public']  # Default role
            }
            
        except jwt.ExpiredSignatureError:
            logging.warning("JWT token expired")
            return None
        except jwt.InvalidTokenError:
            logging.warning("Invalid JWT token")
            return None
        except Exception as e:
            logging.error(f"Error processing JWT token: {e}")
            return None

# Use the custom Security Manager
CUSTOM_SECURITY_MANAGER = CustomSSOSecurityManager

# CORS settings
ENABLE_CORS = True
CORS_OPTIONS = {
    'origins': ['http://localhost:8069', 'https://your-odoo-domain.com'],  # Update with your Odoo domain
    'methods': ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
    'allow_headers': ['Content-Type', 'Authorization'],
    'supports_credentials': True
}

# Embedding settings
FEATURE_FLAGS = {
    "EMBEDDED_SUPERSET": True,
    "DASHBOARD_CROSS_FILTERS": True,
}

# HTTP Headers
TALISMAN_ENABLED = False
WTF_CSRF_ENABLED = False

# Public dashboard settings
PUBLIC_ROLE_LIKE_GAMMA = True

# Cache settings (for performance)
CACHE_CONFIG = {
    'CACHE_TYPE': 'redis',
    'CACHE_DEFAULT_TIMEOUT': 300,
    'CACHE_KEY_PREFIX': 'superset_',
    'CACHE_REDIS_HOST': 'localhost',
    'CACHE_REDIS_PORT': 6379,
    'CACHE_REDIS_DB': 1,
}

# Database connection (Odoo PostgreSQL)
SQLALCHEMY_DATABASE_URI = 'postgresql://odoo_user:password@localhost:5432/odoo_db'

# Additional configurations
SQLALCHEMY_TRACK_MODIFICATIONS = False
SECRET_KEY = 'your-superset-secret-key'
```

3. Customize the configuration:
   - Replace `'your-secret-key-here'` with the same secret key you use in Odoo
   - Update `'origins'` in CORS_OPTIONS with your actual Odoo domain
   - Update the database connection string with your actual PostgreSQL credentials

4. Restart Superset to apply the changes:
   ```
   superset restart
   ```

## JWT Token Format

The JWT token generated by Odoo contains the following fields:

```json
{
  "username": "superset_username",
  "email": "superset_email",
  "first_name": "superset_first_name",
  "last_name": "superset_last_name",
  "exp": 1753720279  // Expiration timestamp (1 hour from creation)
}
```

These values are taken from the Superset user credentials configured in the dashboard settings. You can customize these values for each dashboard to use different Superset users.

## URL Format

The module uses different URL formats for different viewing methods:

1. **For "New Window" view**:
```
https://your-superset-domain.com/superset/dashboard/your_dashboard_id/?jwt=your_jwt_token
```

2. **For iframe embedding**:
```
https://your-superset-domain.com/dashboard/your_dashboard_id/?jwt=your_jwt_token
```

Example for "New Window" view:
```
https://superset.example.com/superset/dashboard/14/?jwt=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VybmFtZSI6ImFkbWluIiwiZW1haWwiOiJhZG1pbkBleGFtcGxlLmNvbSIsImZpcnN0X25hbWUiOiJBZG1pbiIsImxhc3RfbmFtZSI6IlVzZXIiLCJleHAiOjE3NTM3MjAyNzl9.r1QZ3XbbkYEgHbHAH4sqDAZffNVsyOaeGhLaCMwb3cQ
```

**Note**: The exact URL formats may vary depending on your Superset installation. If the above formats don't work, you may need to try different URL patterns such as `/login/?jwt=your_jwt_token&dashboard_id=your_dashboard_id`. The module is designed to use different URL formats for different viewing methods because some Superset installations may require different URL patterns for direct access versus iframe embedding.

**Important**: This URL format is critical for the JWT authentication to work properly. The Odoo module is configured to use this exact format. If your Superset instance requires a different URL format, you will need to modify the `get_embedded_url` method in the `superset_dashboard.py` file.

## Important Notes

1. The JWT secret key must be the same in both Odoo and Superset
2. Make sure the Superset server is accessible from the Odoo server
3. The user roles in Superset should be configured to match the access levels in Odoo
4. Redis is recommended for caching but can be replaced with other caching options
5. After making changes to the Superset configuration, restart the Superset server
6. The CustomSSOSecurityManager class is essential for JWT authentication to work
7. CORS settings must include your Odoo domain to allow iframe embedding
8. The WTF_CSRF_ENABLED = False setting is necessary for JWT authentication to work properly

## Testing JWT Authentication

You can test the JWT authentication with the following Python code:

```python
import jwt
from datetime import datetime, timedelta

JWT_SECRET_KEY = 'your-secret-key-here'  # Must match the jwt_secret in Odoo
JWT_ALGORITHM = 'HS256'

payload = {
    'username': 'admin',
    'email': 'admin@example.com',
    'first_name': 'Admin',
    'last_name': 'User',
    'exp': datetime.utcnow() + timedelta(hours=1)
}

token = jwt.encode(payload, JWT_SECRET_KEY, algorithm=JWT_ALGORITHM)
print(f"Test token: {token}")
print(f"\nTest URL for New Window: https://your-superset-domain.com/superset/dashboard/your_dashboard_id/?jwt={token}")
print(f"\nTest URL for Iframe: https://your-superset-domain.com/dashboard/your_dashboard_id/?jwt={token}")
```

## Troubleshooting

If you encounter issues with the integration:

1. Check the Superset logs for any JWT-related errors
2. Verify that the JWT token is being correctly generated in Odoo
3. Ensure that CORS is properly configured to allow requests from your Odoo domain
4. Test the connection with a simple dashboard before implementing more complex ones
